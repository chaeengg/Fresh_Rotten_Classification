# <img src="https://github.com/weg-9000/image/blob/main/logo_mini.PNG" alt="Example Image" width="32" height="32" style="vertical-align: middle;"> 이미지 분류 및 신선도 분석 시스템

이 시스템은 Azure Custom Vision을 통해 훈련된 TensorFlow 모델을 사용하여, 이미지 내 과일과 채소를 분류하고, 각 품목의 신선도를 평가합니다. 이 모델은 또한 품목의 종류를 분류하여 사용자가 업로드한 이미지를 바탕으로 신속한 분석 결과를 제공합니다.

## 기능

1. **과일/채소 분류**: 업로드된 이미지가 과일인지 채소인지를 판별합니다.
2. **신선도 분석**: 이미지가 신선한 상태인지 썩은 상태인지를 분류합니다.
3. **품목 분류**: 과일/채소의 정확한 품목을 분류합니다 (예: 감자, 토마토 등).

## 요구사항

- TensorFlow 2.x
- Numpy
- Matplotlib
- Pillow
- Azure Custom Vision 모델

## 코드 설명

### 모델 로드

`load_custom_vision_model()` 함수는 Azure Custom Vision에서 내보낸 TensorFlow 모델을 로드하고, 라벨 파일과 함께 모델을 반환합니다. 각 모델은 주어진 디렉토리 내에서 `.pb` 모델 파일과 `.txt` 라벨 파일을 찾습니다.

### 이미지 전처리

이미지는 224x224 크기로 리사이즈되며, 픽셀 값은 0과 1 사이로 정규화됩니다. 이 전처리된 이미지는 모델에 입력으로 사용됩니다.

### 예측

`predict_with_custom_model()` 함수는 TensorFlow 세션을 통해 예측을 실행합니다. 예측 결과는 모델의 출력 텐서를 기반으로 도출됩니다.

### 분석 흐름

1. **과일/채소 분류**: 입력 이미지를 1차적으로 과일/채소로 분류합니다.
2. **신선도 분석**: 분류된 카테고리에 맞는 신선도 모델을 사용하여, 신선도 여부를 판별합니다.
3. **품목 분류**: 마지막으로, 신선도 결과를 바탕으로 품목을 세분화하여 분류합니다.

### 사용방법
1. 모델 디렉토리 내에 Azure Custom Vision에서 내보낸 `model.pb`와 `labels.txt` 파일이 포함되어야 합니다.
2. `YOUR-IMAGE` 경로를 분석하고자 하는 이미지 파일 경로로 변경합니다.
3. `analyze_image()` 함수를 호출하여 이미지를 분석합니다.
